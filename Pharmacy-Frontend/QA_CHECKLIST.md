# Frontend QA Checklist

- [ ] Build passes: npm run build
- [ ] All routes load directly and via navigation
- [ ] Contact form: valid submission succeeds; invalid shows errors; button disabled while submitting
- [ ] Privacy link works from footer
- [ ] Mobile menu and interactions work
- [ ] No console errors in dev/prod preview
- [ ] Metadata correct per route (title/canonical/og)
- [ ] Sitemap.xml and robots.txt accessible
- [ ] No localhost API calls in production build
- [ ] Keyboard accessibility basic checks pass
